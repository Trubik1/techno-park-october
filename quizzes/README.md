# Тесты (Quiz data)

CSV-файлы тестов для импорта в ClassQuiz.

**Формат CSV:** `question, opt_a, opt_b, opt_c, opt_d, correct, explanation`

- `correct` — буква правильного ответа: `a`, `b`, `c` или `d`
- Импорт через панель учителя: «Импортировать» → выбрать CSV

## Базовый тест

| Файл | Тема | Вопросов |
|------|------|----------|
| `drevnie_lyudi_belarus.csv` | Древние люди на территории Беларуси (История, 11 кл.) | 14 |

Для восстановления базового теста в БД:
```bash
cd backend
python seed_quiz_b1v1.py
```
Скрипт идемпотентен — повторный запуск не создаёт дубликатов.
Учитель: `Учитель истории`, PIN: `123456`.

## Как экспортировать тест из БД

```bash
cd quizzes
python export_quiz.py
```

Или напрямую:
```bash
cd quizzes
python export_quiz.py "Название теста"
```

## Как импортировать CSV

1. Войти как учитель
2. Нажать «Импортировать»
3. Выбрать CSV-файл из этой папки
4. Подтвердить импорт
